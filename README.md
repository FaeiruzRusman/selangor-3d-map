# SUO 3D GeoPortal v1.7 — Split Screen Compare Engine

## Fungsi baharu

- Split screen kiri/kanan
- Basemap berasingan bagi setiap peta
- Paparan 2D/3D berasingan
- Default kedua-dua peta ialah 3D
- Sinkronisasi pan, zoom, pitch dan pusat peta
- Pilihan untuk mematikan sinkronisasi
- Butang tukar basemap kiri/kanan
- Hierarki Bandar DPN2 dipaparkan pada kedua-dua peta
- Popup bandar pada kedua-dua peta
- Paparan telefon bertukar kepada split atas/bawah
- Kamera sentiasa menghadap utara

## Penggunaan

Klik **Split Screen** pada header.

Cadangan perbandingan:

- Standard vs Satellite
- 2D vs 3D
- Streets vs Outdoors
- Dark vs Satellite

Fail utama fungsi compare:

```text
compare-engine.js
```
